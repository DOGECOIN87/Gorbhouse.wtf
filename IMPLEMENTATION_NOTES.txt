ARCHITECTURE CHANGES
================================================================================

BEFORE:
  React Frontend → Express.js API → SQLite Database
  - Local ratings only
  - Backend server required
  - No global persistence

AFTER:
  React Frontend → Supabase Client → PostgreSQL Database
  - Global persistent ratings
  - No backend server needed
  - Real-time updates
  - Atomic transactions

================================================================================
ELO IMPLEMENTATION
================================================================================

Formula: Standard ELO rating system
K-Factor: 32
Initial Rating: 1000

Calculation happens in PostgreSQL function vote_and_update_elo():
1. Lock both meme rows (prevent race conditions)
2. Calculate expected scores
3. Calculate new ratings
4. Update both memes atomically
5. Record vote in audit table
6. Return updated ratings as JSON
